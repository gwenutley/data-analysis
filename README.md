# data-analysis
# Overview

This project I was exploring data-analysis. I learned to use pandas library in python to analyze a set of data. 

The data set I chose to use is from the following website https://www.kaggle.com/datasets/thedevastator/u-s-software-developer-salaries/data. 

This specific data set shows software development salaries for different cities in the US. My program was written to go through this data quickly to find which states are the best to live in as a software developer based on the salary and the amount of money needed to live in that state. 

I also added some graph to show the comparison of all of the states, as well as a small graph to show the top 3 states to live in as a software developer and the average income you would bring home after average living expenses.

I decided to write this program to go through the data because I will be  moving to the US in the next few years and I wanted to see what would be the best states to live in persuing a job in software development.
